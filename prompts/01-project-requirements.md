# Store Order & Inventory Mini-System — Project Requirements

## Objective
Build a Laravel-based retail counter system to create customer orders, calculate bill totals, and maintain product stock.

## Core Requirements
- Create customer orders with multiple products.
- Calculate subtotal, tax, grand total, and balance.
- Validate stock and reject insufficient-stock orders.
- Provide order history and low-stock APIs.
- Dispatch order confirmation through Laravel queues.
- Include automated feature tests.

## Technical Requirements
- PHP 8.2+
- Laravel
- MySQL with InnoDB
- PHPUnit
- Database transactions and row locking.

## Expected Deliverables
- Laravel source code
- Migrations and seeders
- API endpoints and billing UI
- Automated tests
- README documentation
